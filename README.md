This repository contains files related to the creation of a canonical data model in TEI format for the ERC LostMa project data. The two ODDs (text and witness) model the data from the release and are illustrated by two XML test files (whose data are partially drawn from the Heurist database). For each ODD there are few hand-encoded XML files used as examples.

All project data are available on the database hosted on [Heurist](https://heurist.huma-num.fr/heurist/?db=jbcamps_gestes&w=a&q=t%3A101) and on the project's [Github](https://github.com/LostMa-ERC).
